# userscripts

[はてなブックマーク：注目コメントと新着コメントを並べて表示](https://raw.githubusercontent.com/banyan/userscripts/master/hatena-bookmark-side-by-side-comments.user.js)

Tampermonkey などの userscript 拡張を入れてから上のリンクを開くとインストールできます。右カラムを隠し、左に注目コメント、右に新着コメントを表示します。画面幅が 800px 以下では縦に並びます。新着コメントのうち注目コメントにも出ているものは非表示にします。

コメント下の関連記事・同じサイトの新着・人気記事などのおすすめ欄も非表示にします。
