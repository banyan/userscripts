# userscripts

[はてなブックマーク：注目コメントと新着コメントを並べて表示](https://raw.githubusercontent.com/banyan/userscripts/master/hatena-bookmark-side-by-side-comments.user.js)

Tampermonkey などの userscript 拡張を入れてから上のリンクを開くとインストールできます。右カラムを隠し、左に注目コメント、右に新着コメントを表示します。画面幅が 800px 以下では縦に並びます。新着コメントのうち注目コメントにも出ているものは非表示にします。

コメント下の関連記事・同じサイトの新着・人気記事などのおすすめ欄も非表示にします。

[Yahoo! JAPAN：ニューストピックスだけを表示](https://raw.githubusercontent.com/banyan/userscripts/master/yahoo-japan-topics-only.user.js)

Yahoo! JAPAN のトップページを、ニューストピックスだけのページにします。主要・経済・エンタメ・スポーツ・国内・国際・IT・科学・地域の全カテゴリを、タブを切り替えずにタイル状に並べて一画面に収めます。主要は大きな文字と写真付きの 2×2 サイズで表示し、ほかのカテゴリは小さなカードで並べます。画面が狭いと 2 列、さらに狭いと 1 列になります。それ以外のコンテンツはすべて非表示にします。
